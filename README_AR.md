مراقبةُ شبكاتٍ قائمة على بروتوكول SNMP مع قناة تنبيهٍ عبر Telegram، على شبكةِ Cisco مؤسسيةٍ محاكاة. كلُّ ما في هذه الحزمة يفتح ويعمل ووُقِّع من طرفٍ إلى طرف (22 اختبارًا أساسيًّا + 7 اختبارات لوحة الويب).

## الجولة في ستين ثانية

1. **افتح المختبر** — انقر مزدوجًا ملف `.pkt`. ثم R1-Core ← CLI ← ‏`show snmp`: كلُّ موجّهٍ ومبدّلٍ يحمل السياسةَ نفسها.
2. **اقرأ التقرير** — الفصل الثالث (التصميم) ← الخامس (المحرّك) ← السابع (النتائج المقيسة).
3. **شغّل النظام** — راجع `monitoring-system/README.md`: أوامرٌ قليلة وتصلك التنبيهات على هاتفك (يلزم توكن BotFather — خمس دقائق).
4. **افتح لوحة الويب** — `python3 dashboard.py` ثم `http://localhost:8080`: حالةٌ حيّةٌ تتحدّث كل ثانيتين.

## ملاحظة هندسية صادقة

‏Packet Tracer محاكٍ: تهيئةُ أجهزته لـSNMP أمينةٌ لكنها غير قابلةٍ للوصول عبر مقابس UDP حقيقية من برنامجٍ خارجي. لذلك يقترنُ المختبرُ (مستوى التصميم) بستةِ وكلاء SNMP مطابقين للبروتوكول (مستوى البيانات الحيّ) يكشفون معرّفات CiscoOIDs نفسَها والـcommunity نفسَها ومضيفَ الـTraps نفسَه. وكودُ المراقبة جاهزُ الإنتاج: لاستهداف موجّهاتٍ حقيقية تُغيَّر عناوينُ النهايات في ملف YAML واحد — لا شيءٌ غير ذلك.
